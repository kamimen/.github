# kamimen (紙面)

Tools for laying out Japanese newspaper pages (新聞の紙面) on the web.

| Repository | Install | Description |
|---|---|---|
| [shinbun-css](https://github.com/kamimen/shinbun-css) | `npm install @kamimen/shinbun-css` | Dependency-free CSS: vertical and horizontal writing, column grid, column-spanning headlines |
| [shinbun-components](https://github.com/kamimen/shinbun-components) | `npm install @kamimen/shinbun-components` | Web Components built on shinbun-css |
| [astro-theme-shinbun](https://github.com/kamimen/astro-theme-shinbun) | `npm create astro@latest -- --template kamimen/astro-theme-shinbun` | An Astro blog theme that reads like a newspaper page |
| [shinbun-maker](https://github.com/kamimen/shinbun-maker) | [Open the app](https://kamimen.github.io/shinbun-maker/) | A web app that lays out a page from text and images and saves it as PNG or PDF |

Japanese typesetting terms are written in Japanese as well, for example vertical writing (縦組み, *tategumi*). See the [glossary](https://github.com/kamimen/shinbun-css#glossary).
