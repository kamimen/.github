# kamimen（紙面）

日本の新聞の紙面を、HTML と CSS で組むためのツールを作っています。

| リポジトリ | 内容 |
|---|---|
| [shinbun-css](https://github.com/kamimen/shinbun-css) | 縦組みと横組み、段組み、段抜きの見出し、題字、広告枠、表の CSS |

issue や Pull Request は、各リポジトリで受け付けています。貢献の手順は、[CONTRIBUTING.md](https://github.com/kamimen/.github/blob/main/CONTRIBUTING.md) に書いています。

---

Tools for laying out Japanese newspaper pages with HTML and CSS. Each repository has its own README, and the main one is [shinbun-css](https://github.com/kamimen/shinbun-css).
